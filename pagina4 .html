TEMA 3: ESTILOS DIRECTOS Y ATRIBUTOS DE COLOR

Explicacion

Podemos modificar el aspecto visual directamente en las etiquetas usando atributos como bgcolor o estilos CSS en linea (style).

<!-- Cambiar color de fondo en body -->
<body bgcolor="BLUE">

<!-- Estilo CSS inline para color y tamaño -->
<p style="color: red; font-size: 80px;">Texto grande y rojo</p>
