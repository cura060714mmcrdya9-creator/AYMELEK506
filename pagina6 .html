TEMA 6: ESTILOS DE TABLAS CON CSS

Explicacion

Para darle mejor diseño a las tablas, usamos propiedades CSS:

  • border: Define el grosor y color del borde (ej. `1px solid black`).
  • border-collapse: Fusiona los bordes dobles en uno solo para que se vea limpio.
<style>
  table, th, td { border: 1px solid black; }
  table { border-collapse: collapse; width: 100%; }
</style>
