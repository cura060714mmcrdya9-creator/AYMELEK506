1. Explicacion Didactica

Todo documento de pagina web inicia con una estructura fundamental que le indica al navegador web como debe interpretar y desplegar el contenido:

  • <html>: Etiqueta raiz que encierra todo el codigo web.
  • <head>: Seccion invisible que contiene informacion general y titulos de la pestaña.
  • <title>: Define el titulo visible en la pestaña superior del navegador.
  • <body>: Cuerpo del documento donde va todo el contenido visible (textos, imagenes, etc.).
  • <h1>: Titulo o encabezado principal dentro de la pagina.
  • <p>: Parrafo de texto normal.

2. Ejemplo de Codigo Practico

Copia y pega este codigo base en tu bloc de notas:

<html>
<head>
  <title>Mi Primera Pagina web 506</title>
</head>
<body>
  <h1>Hola Mundo</h1>
  <p>Esta es mi primera pagina web.</p>
</body>
</html>
