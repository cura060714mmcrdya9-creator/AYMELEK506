MYSQL TEMA 6: ELIMINACION Y RENOMBRADO

Explicacion y Comandos

Utilizados para borrar estructuras completas de la base de datos o cambiarles el nombre:

-- Como eliminar una tabla completa
DROP TABLE nombre_tabla;

-- Como renombrar una tabla
RENAME TABLE actual TO nuevo;
-- o tambien:
ALTER TABLE actual RENAME TO nuevo;
