1. Sintaxis de Etiquetas de Estructura

En las practicas de HTML utilizamos etiquetas clave para agregar hipervinculos, imagenes y contenedores:

  • <a href="...">: Permite crear un enlace hacia otra pagina web o archivo.
  • <img src="...">: Muestra una imagen mediante su ruta de origen.
  • <div>: Contenedor en bloque usado para agrupar varios elementos a la vez.
  • <span>: Contenedor en linea para dar formato a partes especificas de un texto.

2. Ejemplo de Codigo Practico

<!-- Ejemplo de hipervinculo e imagen -->
<a href="https://www.google.com">Ir a enlace de sitio web</a>

<img src="foto.jpg" alt="Foto de ejemplo" width="200">

<!-- Ejemplo de contenedores -->
<div>
  <p>Texto dentro de un contenedor en bloque</p>
  <span style="color:red;">Texto resaltado con span</span>
</div>
